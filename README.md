# COMP5970Project
Semester Project for COMP5970 Assistive Computing

I wanted to point out that I did not use TypeScript, TailwindCSS, and Postgres like I outlined in my Technical Proposal. This is because I received an email from Maryam explaining that it must be built in HTML, CSS, and JavaScript. And since this has to be hosted on Github Pages, I am unable to use a database. However, I have implemented JavaScript to act like a database. Just every time the page is refreshed, the information in the database will be erased. 

All webpage colors have been tested and are in compliance.

Webpage correctly navigable via keyboard controls (Tab, Enter), even though it is just a mobile page.

Webpage has been tested with every phone layout included in Firefox.
